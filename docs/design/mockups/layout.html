1Sidebar mode switch. Playground shows the built-in tracks and the schema of the track's sandbox database. Connections shows your saved Postgres and MySQL servers. ⌘\ collapses the sidebar.
2Schema tree. Tables with row counts and columns with their types. Clicking a table opens it in a read-only browse tab. Drag a name into the editor to insert it as text. This is a manual action, not autocomplete.
3Tabs. Each challenge tab keeps its own draft, and drafts survive app restarts. "Scratch" tabs are freeform. ⌘T opens a new tab, ⌘W closes one.
4Two actions. Run (⌘↵) runs your SQL. Check answer (⌘⇧↵) runs it and grades it. Running the selection runs only the highlighted SQL.
5Results grid. Draws only visible rows, and columns can be resized. NULLs show as dim italic. Copy as TSV, CSV or JSON. The Plan tab shows EXPLAIN QUERY PLAN.
6Status bar. Which database you're connected to, row count, how long the query took, and cursor position. While a query runs, it shows a live timer and a cancel button (⌘.).
7Challenge brief. The story prompt, the expected column names and row count, whether order matters, and concept tags. No hints that write SQL for you. ⌘⌥I toggles the panel. In Connections mode this space becomes a row inspector.
⌘KCommand palette. Jump to any track, challenge, table, tab, connection or setting by name. It's for navigating only and never suggests SQL.

Feedback tells you what's wrong, never how to fix it. Checks run in order: columns, then row count, then which rows, then row order. The row diff and the full expected result are opt-in, so you can't spoil an answer by accident. A correct answer sets off a short aurora pulse: about 600 ms of teal light across the window, with the progress segment glowing. Satisfying but brief, and it respects the macOS Reduce Motion setting.

Opening the app should feel like coming back to something. A personal greeting, how far you are from finishing a track, and a streak that counts days with at least one solved challenge. The work side is one click away. The app opens in about 200 ms, faster than Electron apps like Beekeeper can, and that speed is part of the appeal.
